## About me

I'm an **Information Technology Engineering student** and software developer based in Chile, focused on building maintainable backend systems, designing APIs, and deploying containerized applications.

I work with **REST and GraphQL**, relational and NoSQL databases, and modern web architectures. I'm especially interested in **software design, CI/CD, infrastructure, and DevOps practices**.

- 🔭 **Building:** full-stack platforms, backend services, and automation workflows.
- 🛠️ **Working with:** TypeScript, NestJS, Next.js, PostgreSQL, Docker, and Podman.
- 📚 **Exploring:** system design, cloud infrastructure, observability, and deployment automation.
- 🎮 **Beyond code:** gaming, music, astronomy, and TV series.
